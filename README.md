# Retrace

Observe a demonstrated desktop workflow and turn its evidence into documentation developers can review and use to modernize an application.

- `web/`: Next.js landing page and review workspace.
- `macos/`: native macOS recorder (integration milestone).
- `backend/`: Python API, capture ingestion, and bounded Nemotron analysis.
- `spacetimedb/`: shared state module.

Recordings remain local until the user explicitly uploads them. Agents analyze evidence; they never operate the recorded application.
